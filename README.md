# Jiji’s Crochet Shop

Public site for **[jijiscrochetshop.com](https://jijiscrochetshop.com)** — handmade amigurumi and custom crochet from Missouri.

Served with GitHub Pages from this repository (`main` / root). The `CNAME` file maps the custom domain.

## Custom orders
The custom-order form opens the visitor’s email to `hello@jijiscrochetshop.com`. Point that mailbox (or Namecheap email forwarding) at the real inbox, or change the address in `custom.js` / the footer.

## Local preview
Open `index.html`, or from this folder:

```
python3 -m http.server 8080
```
